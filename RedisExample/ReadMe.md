Kısacası, 0-0 bir joker karakter veya bir ayar değildir; teknik olarak geçerli bir ID formatıdır (zaman damgası 0, sıra numarası 0). Anlamı "en baş" veya "en küçük"tür.

XGROUP CREATE içinde kullanıldığında: Stream'in en başı.

XAUTOCLAIM / XPENDING içinde kullanıldığında: Bekleyenler listesinin (PEL) en başı.
